# CS-305

This repository is for the code base that is for my client, Artemis Financial. Artemis is a financial consulting firm that handles sensitive data regarding different kinds of financial accounts. They hired me to help with the security of their web application. Their software requirements where that their web application gets updated to the newest standards, the inclusion of secure data transfer and for me to find any vulnerabiliteies in their web application. 

When I found a vulnerability in their software, I feel like I was able to do a great job in not only documenting what was but also fixing or recommending a fix to the problem. It's crucial to practice secure coding. Not only does it does it keep the company safe but it also keeps their customers safe. If a company has security vulnerabilities that get exploited then the company in question could face legal trouble. As exploits are used and abused, a company could easily lose customers. If a company loses too many customers, they could go out of business. At the end of the day, it is of upmost importance for a company to have secure code. 

The hardest part of the vulnerability assessment for me was getting my first OWASP dependency check to properly work. It was easy to put the OWASP check into the pom.xml was the easy part, but configuring the Maven check it was really stumped me. After I did it the first time, it was a lot easier after that. 

One way I was able to increase the layers of security was enabling HTTPS and adding encryption. This allowed for me to encrypt the data that is being sent while also making sure that the data that is being sent is being sent to and from are coming and going from the appropriate client and server. For future applications, I would use the OWASP checker before I start of assessing the security of the application. I really enjoyed how well it was able to tell me all the vulnerabilities which I feel like would be a great place to start when trying to analyze a new piece of software. 

While working on this project, I had one thing to fall back on to help me make sure that the application was functional and secure and that was rerunning the application over after any change. This allows me to see how things change bit by bit. This way I know that what I changed or added is actually working. When it comes to the security aspect of the application, I would rerun the OWASP dependence check to see if what I did was able to make a change. 

When a future employer ask me for an example of my work that show cases my skill, I would show them this project when I talk about my security skills. My future employer will be able to see that I can not only find security problems but also be able to implement change, or at least be able to recommend what we should do to improve the security of an application.
